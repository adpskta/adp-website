# 00_inbox — HP用素材の受け渡しフォルダ

ここに素材を入れて、Claudeに「inboxに入れたよ」と言えばHPに反映されます。

## 使い方

### 顔写真・事務所写真
`profile/` に画像を入れる。ファイル名は自由。
複数入れてもらえれば、使う写真の候補を提案します。

### 新しい事例を追加するとき（今後ずっとこの手順）
1. `00_inbox/` の中に**事例名のフォルダ**を作る（例：`00_inbox/世田谷の住宅/`）
2. 写真を入れる（枚数自由・掲載順に並べたい場合はファイル名先頭に 01_ 02_ と番号）
3. 同じフォルダに `メモ.txt` を入れる（雑な走り書きでOK。以下があると良い）
   - 施主の要望・きっかけ
   - a.d.pの提案・工夫したこと
   - 所在地（市区まで）・用途・延床・構造・竣工年
   - 設計/施工/写真のクレジット
   - 施主の一言コメント（あれば）
4. Claudeに「inboxに◯◯を入れた」と伝える → 文章化・画像最適化・ページ生成まで自動でやります

### 既存事例に情報を追加するとき
`00_inbox/` に `既存_事例名.txt` を作ってメモを書く（例：`既存_北鎌倉の増築.txt`）

※ このフォルダ内の原本は勝手に削除しません。反映後もバックアップとして残ります。
